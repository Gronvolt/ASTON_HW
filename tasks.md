# Java: задачи для подготовки к собеседованию

## 01. Проверка на чётность

**Сложность:** простая

Напиши метод `isEven(int n)`, который возвращает `true`, если число чётное, и `false` в противном случае.

Примеры:
- `4` → `true`
- `7` → `false`
- `0` → `true`

**Темы:** остаток от деления, условия, `boolean`.

## 02. Максимум из трёх чисел

**Сложность:** простая

Напиши метод `maxOfThree(int a, int b, int c)`, который возвращает наибольшее из трёх чисел. Одинаковые максимальные значения должны обрабатываться корректно.

Примеры:
- `(3, 8, 5)` → `8`
- `(4, 4, 2)` → `4`
- `(-5, -2, -9)` → `-2`

**Темы:** условия, сравнения.

## 03. Сумма от 1 до N

**Сложность:** простая

Напиши метод `sumToN(int n)`, который возвращает сумму целых чисел от `1` до `n` включительно. Если `n <= 0`, верни `0`.

Примеры:
- `5` → `15`
- `1` → `1`
- `0` → `0`
- `-3` → `0`

**Темы:** циклы, накопление суммы, условия.

## 04. Количество цифр

**Сложность:** средняя

Напиши метод `countDigits(int n)`, который возвращает количество цифр в числе. Минус не считается цифрой. Число `0` содержит одну цифру.

Примеры:
- `527` → `3`
- `-42` → `2`
- `0` → `1`
- `1000` → `4`

**Темы:** циклы, целочисленное деление, обработка отрицательных чисел.

## 05. Сумма цифр

**Сложность:** средняя

Напиши метод `sumDigits(int n)`, который возвращает сумму цифр числа. Знак минус игнорируется.

Примеры:
- `1234` → `10`
- `-507` → `12`
- `0` → `0`

**Темы:** остаток от деления, целочисленное деление, циклы.

## 06. Переворот числа

**Сложность:** средняя

Напиши метод `reverseNumber(int n)`, который возвращает число с цифрами в обратном порядке. Считай, что результат помещается в `int`. Сохраняй знак отрицательного числа.

Примеры:
- `1234` → `4321`
- `560` → `65`
- `-123` → `-321`

**Темы:** циклы, остаток от деления, целочисленное деление, построение числа.

## 07. Простое число

**Сложность:** средняя

Напиши метод `isPrime(int n)`, который возвращает `true`, если число простое, и `false` в противном случае. Числа меньше `2` не являются простыми.

Примеры:
- `2` → `true`
- `9` → `false`
- `1` → `false`

Дополнительное условие: оптимизируй проверку, проверяя делители только до квадратного корня из `n`.

**Темы:** циклы, условия, остаток от деления, оптимизация.

## 08. Вывод простых чисел до лимита

**Сложность:** средняя

Напиши метод `printPrimeNumbers(int limit)`, который выводит все простые числа от `2` до `limit` включительно. Для проверки каждого числа используй отдельный метод `isPrime(int n)`.

Пример: `printPrimeNumbers(20)` выводит:

```text
2
3
5
7
11
13
17
19
```

**Темы:** вложенная логика, циклы, вызов методов, декомпозиция.

## 09. Второй максимум без сортировки

**Сложность:** сложная

Напиши метод `secondLargest(int[] numbers)`, который возвращает второе по величине уникальное число в массиве. Сортировать массив нельзя.

Примеры:
- `[3, 8, 5, 8, 2]` → `5`
- `[7, 7, 4]` → `4`
- `[5, 5, 5]` → второго максимума нет.

Для последнего случая самостоятельно выбери и объясни способ обработки: например, выбросить исключение или вернуть специальное значение.

**Темы:** массивы, переменные состояния, условия, один проход по данным.

## 10. Число Армстронга

**Сложность:** сложная

Напиши метод `isArmstrong(int n)`, который проверяет, равно ли число сумме своих цифр, возведённых в степень, равную количеству цифр числа.

Например:
- `153` → `true`, потому что `1³ + 5³ + 3³ = 153`
- `370` → `true`
- `123` → `false`

Отрицательные числа считать не подходящими под определение.

**Темы:** несколько циклов или проходов, цифры числа, степень, композиция методов.
